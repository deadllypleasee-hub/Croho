# CHRONOS — Всемирная история

Android-приложение на русском языке: 10 глав по 5 вопросов, пояснения к каждому ответу и финальный экзамен. Работает полностью офлайн, без аккаунта, рекламы и разрешения на интернет. Android 6.0 и новее.

## Как играть

Пройдите главы по порядку. Четыре правильных ответа из пяти открывают следующую главу. После всех десяти глав доступен экзамен: 20 случайно выбранных вопросов, по два из каждой главы; для сдачи нужно 16 правильных ответов. Повторы не ухудшают лучший результат.

Результаты и текущая попытка сохраняются на устройстве, в том числе при закрытии приложения и повороте экрана. Можно вернуться к ленте времени и продолжить попытку. Удаление приложения, очистка его данных или подтверждённый сброс внутри приложения удаляют прогресс.

## APK
[GitHub Actions → Build CHRONOS APK](https://github.com/deadllypleasee-hub/Croho/actions/workflows/android.yml) → последний успешный запуск → Artifacts → **CHRONOS-APK**. Для скачивания артефакта нужен вход в GitHub. Распакуйте ZIP и установите **CHRONOS.apk**, разрешив установку из выбранного источника в настройках Android. В ZIP также есть контрольная сумма SHA-256. Артефакт хранится 90 дней; новый запуск создаёт новый файл.

Это установочная **debug-сборка**, подписанная отладочным ключом, а не релиз для Google Play. Ключ между запусками CI не сохраняется; Android может потребовать удалить старую сборку перед установкой новой, что удалит её прогресс.

## Сборка и проверки

Нужны JDK 17 и Android SDK Platform 35. Gradle 8.9 загружается через включённый Wrapper с проверкой SHA-256; Android Gradle Plugin — 8.7.3.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest # с подключённым устройством или эмулятором
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Workflow запускается при push в `main`, в pull request и вручную через **Run workflow**. Он проверяет банк вопросов, подсчёт баллов, порог прохождения, открытие глав и выборку экзамена; выполняет Android Lint, собирает APK и проверяет сохранение попытки, прохождение главы и экзамена на эмуляторе Android 15. APK публикуется в артефактах только после успешных проверок. Отчёты доступны в **CHRONOS-checks**.
